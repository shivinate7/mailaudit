# The native key scan skips SwiftUI view state

**What.** No lane scans SwiftUI view state, such as `@State` in a view. The key scan covers the Packages model, its rows, the masthead model and its cells, the backup export and the ledger file. The gap closes when a lane adds that scan.

**Status:** open. The owner names the lane.

# Orphaned mail never decides anything

The user often buys the same cheap card from many sellers, so near-duplicate packages are normal and expected. The app may rank which outstanding packages an envelope could match. It must never auto-assign a match, and it must never check off a card the user did not record by hand. An equally-good tie is shown as a tie, with no emphasis on any option. This rule came directly from the user and must not be simplified away as friction.

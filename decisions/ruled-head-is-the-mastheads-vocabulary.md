# The ruled head continues the masthead

The control region uses the masthead's own visual language. It uses hairline rules, uppercase mono micro-labels, and Cochin values. It has no boxes and no fills except the active-state accent. It replaced a region built from mismatched parts, with two radii, two font families, three type sizes, a native select, and a native date pair.

# When a chokepoint has two branches

A shared chokepoint can have two read paths. A mutant on one branch can hide behind the other branch computing the right answer on its own. Dropping the refund exclusion from one list still left every masthead figure correct, because those figures derive from a second list that excludes refunds independently. Only a test on the second branch, the orphaned-mail candidates, could see the mutant. A chokepoint with two branches needs an assertion on each one.

# The Duo tab bar may clip at large text sizes

**What.** The open Duo's tab bar is a fixed 64 pt pill, while its labels scale with Dynamic Type. At accessibility text sizes, four labels across the right page may clip. No run has measured it.

**Status:** open. Measure it at the largest accessibility size on the open Duo, then let the pill grow or drop the labels to symbols.

**Decision:** `duo-card-in-hand`.

# The Post offer scrolls the sender off the page

**What.** On the open Duo, when a held card's Post offer shows, the answer page scrolls it above the keys. That scroll takes "It came from" and the seller's name off the top of the page. So "Post … here" no longer names where "here" is, and rows run under the clock and status icons. It happens on each held card. The gap closes when the offer and the sender show together above the keys, no content sits under the status bar, and a test pins both.

**Status:** open.

**Decision:** `duo-card-in-hand`.

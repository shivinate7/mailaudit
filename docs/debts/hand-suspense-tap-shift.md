# A Suspense tap shifts the match list under the finger

**What.** On Card in Hand, tapping a match whose name two open envelopes share collapses the list to the tapped row, which slides up to the first slot under the finger. The Suspense box opens below the list. No test pins it. A likely fix is to hold the list's height until the next keystroke. The gap closes when a tap on a match moves no row, and a test pins it.

**Status:** open.

**Decision:** `no-layout-shift-under-pointer`.

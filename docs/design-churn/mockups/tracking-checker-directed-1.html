Tracking checker: one verdict chip per order

Designer kind: directed. Direction: status-chip: one verdict chip per order, nothing else.

Two concepts. Each adds one chip to a tracked package card on Packages, and nothing else: no new tab, no list, no filter. Tap any chip. Light theme only: the app is held to light.

Flip chip

Today's "● tracked" glyph grows into a chip on the order id row. The chip shows the verdict. A tap flips it, in place, to the carrier's latest scan and its time. A second tap flips it back. The row is already 45 pt tall for the order id link, so the chip adds no height.

Slot verdict

The verdict takes the card's status slot, where the "3 left" pill sits today, and carries the count with it: one chip per order says both where the package is and what is still out. A tap opens the reading: the carrier's latest scan, its time, the number, the claim date, and two ways on.

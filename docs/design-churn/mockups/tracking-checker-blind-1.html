Tracking checker

Two concepts for one job: see what the carrier says, get a plain verdict, and hear early when a package needs you. Every tap works. Each concept draws the Duo folded, the Duo open, a large phone, and the folded Duo at the largest text size.

Options on this page

Watch list: a list sorted by what needs you, with a detail page.
Mail call: a daily roll call that asks you about each package, one at a time.
Claim-window runway: a bar on each package that needs you, which shows how many days are left to claim.
Stuck after N days: a setting for how many days with no scan count as stuck (Watch list, Alerts).

Mail call

The bold one. No list comes first. The app asks one question per package that needs you: "Is it here?" You answer each one with your thumb. When it has no more questions, it says so. The full list sits behind one button.

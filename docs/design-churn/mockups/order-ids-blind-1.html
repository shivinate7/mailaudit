Order numbers: read, copy, open

Blind designer, order-ids-blind-1. Three ways to give the full order number, a one-tap copy, and a link to that one order. Each way is drawn on the two-screen device folded, then open, then on a large phone, then folded at the biggest accessibility text size. Every frame is live: tap, type and drag.

Number deck

Bold. No list first: one order fills the screen, its number set large, one dash group per line. The number itself is the copy button. Swipe or step between orders; find one by any part of its number. Open, the left page holds the number and the right page holds that order's own page.

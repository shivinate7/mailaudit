Look

Ledger. A list of packages, a detail page, and a sheet for each date or stamp. A second step in the sheet shows each value that will change, struck through beside its new value, before anything is saved. The Changes tab undoes any change.

Correction slip, the bold option. There is no package list first. The person picks what went wrong and writes the fix as one sentence; each blank in it is a tap target. Under the sentence, a carbon copy shows the whole record as it will be. Filing is append-only: Reverse files a new slip, so the record of every change stays.

Day board. The first screen is a calendar. Each dot is a package on the day it came. To fix a wrong day, pick the package up and tap the day it really came; a bar shows the change before it is saved. A switch turns the same calendar to order days, where two taps pick a range.

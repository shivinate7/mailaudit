Today

Native: the number is plain 10.5 pt text under the detail line, no link, no copy (ItemLine.lines). Web: the number is a button that opens the order in Packages, and it ends in an ellipsis at narrow widths (ItemRow, onOpenOrder). TCGplayer is reached only from the package header (tcgplayerOrderUrl).

Order slip

The number becomes a slip: the whole number, at the seller's size and broken only at its dashes, is the link to that order on TCGplayer. One tap opens it. The slip's tail is a copy key: one tap copies the number, and "Copied" shows on the key. A long press opens the system menu: Open on TCGplayer, Copy Order Number, Share.

Open and carry

One link does the whole job. A tap copies the number and opens the order on TCGplayer, where the message to the seller is written, so the number is ready to paste. "Copied" shows at the press, then Safari opens. No second control on the line. A long press offers each half alone: Copy Order Number, or Open without Copying, which keeps what is already on the clipboard.

Guided checklist

A list you work down. The first screen holds one sentence and one button. After the file comes in, three numbered steps sit on top of the real list and tick off as you go, so the person learns the tool by using it. Tabs: Waiting, In hand, Envelopes.

Mail tape

Bold. No tabs and no list as home. Home is a tape of every step taken, newest at the bottom, with one field in thumb reach that asks who the mail in your hand is from. Every stamp, import and envelope prints a line, so nothing is ever wiped and each step can be undone in place.

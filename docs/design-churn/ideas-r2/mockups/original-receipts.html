Frames: the phone (folded pose) is 390 by 844; the two-screen pose is two 390 by 844 screens with a hinge. The repo's device list writes no size, so both are drawn at the brief's size. The two-screen pose is its own layout: a list on the left and its detail on the right. Type uses the iOS Dynamic Type styles at the default size; tap targets are at least 44 by 44 pt. No desktop web frame: the plan names no web width. Labels: grey "Today" is in the app now, gold "Round 1" is round 1's import receipt idea this builds on, blue "New" is this direction.

Design choices

  1. One slot, two contents. The receipt and the drift hold share one fixed-height panel in the import sheet. Gain: Merge and Cancel never move. Loss: a short receipt leaves blank space. Pick: fixed slot.
  2. Source line on two fixed lines. The plan says one line; at 390 pt the full line does not fit. Gain: the file name never truncates. Loss: one more line of height. Pick: two fixed lines; the second ellipsizes.
  3. Protected columns show a guess but never pick it. Cost, quantity, order number and product name under a new name stay unset until tapped. Gain: no wrong price slips through. Loss: one more tap per format change. Pick: as the plan says.
  4. Merge stays off, with the reason under it. "Answer 2 columns to merge." Gain: the owner sees why. Pick: this.
  5. Address cells hidden on screen. Raw views mask the ship-to cell as "address hidden"; the kept file is unchanged. Not in the plan. Gain: a shared screenshot leaks no address. Loss: the view is not byte for byte. Pick: mask. Owner grant: yes.
  6. Delete keeps the rows. The delete sheet says the ledger rows stay and only "show raw line" stops working. The plan names the sheet, not this outcome. Owner grant: yes.
  7. Sync mark is shape plus words. Filled dot "On server", ring "Uploading", square "On server only". Gain: readable without colour. Pick: this.
  8. Re-read groups start undecided. Neither Accept nor Reject is pressed, and Apply counts only accepted groups. Pick: as the plan says.
  9. Two-screen pose. Left: the list or the import sheet. Right: the file, the column samples, the provenance pane or the diff. Gain: a mapped column sits beside its raw cells. Pick: this.
  10. Sample clock. The page is set in July 2027, so a sources list exists after receipts start in 2026-11. The 400-file state is set in June 2028.

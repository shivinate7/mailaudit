Picks drawn here (the plan's recommendations)

  • Shelves are free text, with recent shelves as chips.
  • One shelf per order line. A ×3 line cannot split yet.
  • Cards received before this feature read "Unsorted" (see Pale Wisp).
  • Undo reverses the tick and its shelf as one log entry.
  • The tray shows before any tick, so the layout stays still.
  • Orphaned cards can take a shelf (Orphaned tab).

Not drawn

  • Splitting one line across two shelves, move history, and backfilling old cards: not in the first slice.
  • Where a shelf is saved: unknown. The saved-state shape is fixed, so the owner rules first.
  • The web layout. This page draws the iPhone only.
  • Device sizes: the repo writes none, so each screen is a nominal 360 by 780.

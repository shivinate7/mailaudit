Plan points not drawn as screens

  1. The deputy pass is a separate credential from the device key. It allows one act: report a count.
  2. The buyer's device computes the expected range and posts only the rounded range. The server never sees the item list.
  3. A tray report is stored beside the check-in records, not inside them, so the saved-state shape keeps its form.
  4. No photo of the stack: mail shows names and addresses.

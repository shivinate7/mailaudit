How to read it

  • Every frame is live. Press an event chip, a count in the strip, a row, "Need for…", the stepper, the stamps and the tabs. The state picker resets the sample. Each state has a link: #s=<state>, and &t=dark or &t=light sets the theme.
  • The sample's "today" is fixed at Sat, Nov 28, 2026, so day counts do not drift. "Event today" moves it to Dec 3 and "Past event" to Dec 4.
  • Dashed "Today:" marks what the app has now. Dashed "New:" marks what this direction adds. The Labels button hides both.
  • Drawn reading for refunded copies: they sit in the at-risk count and are labelled "not coming". The plan's edge state ("count as not coming") and its slice-1 rule (at risk includes refunded) disagree, so this is a choice, not the plan's.
  • Not drawn: a desktop web width, because the plan names no web target. Later slices 3 to 5 (last safe re-buy day, deck-list coverage, proxy sheet) are out of the plan's screen states.

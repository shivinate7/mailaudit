Orphaned composer: keep Save clear of the keys

Designer kind: informed. Owner page item 84. iPhone Duo folded, 466 x 678 pt. Light only.

The ready audit flags the "1 card" count and the Save envelope button. Both colour pairs clear 4.5:1. The empty audit passes on the same count in the same colour. What differs is the place: adding a card pushes the Save row 62 pt down, under the keys, and nothing scrolls it back. The audit then reads keyboard pixels inside the two frames. The fix is a margin: the Save row stays 56 pt above the keyboard's reported top, re-scrolled each time the composer changes height.

What this mockup shows, from the plan

  1. It writes the same check-ins as today. The package list stays; "Scan cards" is a new way in.
  2. Every tick lands in the recent-checks log, and its undo is what makes an auto-tick safe.
  3. A card in no open order goes to the existing orphaned pile. A scan only proposes a match there; it never assigns one.
  4. "Missing one" leaves the line open, so the lost-mail warning keeps counting it.
  5. Matching is by card name. Set and collector number would only break ties, and the CSV may not carry them.
  6. Camera frames are not kept, except the one photo taken after "Problem".
  7. On web there is no camera: it opens the type-ahead box (state 8) instead.
  8. Frame size is nominal, 375 x 780 per screen: no device size is written for this repo.

Shipping drag idea mockup, not built

Ranks your orders by how much the postage cost against the cards, so you can see which buying habit costs you postage. It changes nothing in your data.

Owner decisions

Each control redraws both screens. The recommended pick is marked "rec" and is the default.

What does the ratio compare?

Card subtotal against shipping, both straight from the order rec. The other option is landed cost, which needs the landed-cost idea built first, so it is not drawn.

When does an order count as drag?

When shipping is above the card subtotal, so above 100%, fixed rec. The list draws this as a line.

Free-shipping hints

They are guesses from your own past orders, and they can nudge spending. Nothing is fetched from sellers.

Scope

The first slice shows the summary line and the ranked list only. No grouping by seller and no hints.

Sizes are assumed: no Duo size is written, so the folded screen is drawn at 390 × 844 pt and the unfolded one at 780 × 844 pt. Type sizes are the Dynamic Type defaults on Apple's typography page (read 2026-11-21). "Today" in this sample is Nov 21, 2026. Avg is total shipping ÷ total cards, so the figures add up.
